# Scientific Methodology

PARADIGM ZERO generates controlled simulated universes with a hidden ground-truth equation. Observations include noise and omit hidden variables. Candidate hypotheses are generated via symbolic regression and evaluated on held-out test data. Metrics: equation recovery (exact symbolic match), prediction accuracy (R2), generalization gap, experiment efficiency, reproducibility. Discoveries are compared against ground truth. Results are valid only for the simulated universe, not real physics.
